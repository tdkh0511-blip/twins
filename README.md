# 株式会社Twins family Webサイト制作プロジェクト

「ツインズリハビリ訪問看護ステーション」および「ツインズケアプランセンター」の公式Webサイト構成に基づき、モダンで信頼感と温もりのあるデザインで作成したレスポンシブWebサイトです。

## 📁 ディレクトリ構成

```
project/twins/
├── index.html          # メインページ（全セクション・レスポンシブ対応）
├── css/
│   └── style.css       # デザイン・レイアウト・アニメーションスタイル
├── js/
│   └── main.js         # ナビゲーション制御・FAQアコーディオン・お問い合わせモーダル
└── README.md           # 本説明ドキュメント
```

## 🌟 主な特徴と実装内容

1. **温もりと清潔感・信頼感のある医療介護デザイン**
   - ブランドカラー（温かみのあるオレンジと安心感のあるグリーン）をベースに、シニアやご家族が読みやすい高コントラスト・大きな文字サイズ設計。
2. **完全レスポンシブ対応（スマホ・タブレット・PC）**
   - スマートフォン表示時にはスムーズにスライドするハンバーガーメニューと、ワンタップ発信可能な電話番号UIを搭載。
3. **充実したサイト構成**
   - **ヘッダー & トップバー**: 24時間緊急対応の案内、直通電話番号（訪問看護・ケアプランセンター個別）
   - **ヒーローセクション**: キャッチコピー「寄り添う心、家族のような温もりを。」、CTAボタン、安心の統計バッジ
   - **ツインズファミリーの想い**: 社名の由来（ツインズ×ファミリー）、基本理念、代表メッセージ、3つの強み
   - **サービス案内 01**: ツインズリハビリ訪問看護ステーション（看護師による医療的ケア、PT/OT/STによる機能訓練・嚥下訓練）
   - **サービス案内 02**: ツインズケアプランセンター（居宅介護支援、ケアプラン作成無料案内）
   - **ご利用の流れ**: STEP 1〜4で初めての方でも分かりやすく図解
   - **対応エリア**: 茨木市、高槻市、摂津市、吹田市などの北摂重点地域案内
   - **事業所概要・アクセス**: 所在地（阪急南茨木駅徒歩5分）、営業時間、連絡先
   - **採用情報（リクルート）**: 働きやすさ・アットホームな職場の魅力、募集職種
   - **よくあるご質問（FAQ）**: クリックで開閉するアコーディオンUI
   - **お問い合わせフォーム**: 入力バリデーションと送信完了モーダルポップアップ付き
   - **フッター**: サイトマップ、著作権表記、ページトップへ戻るボタン

## 🚀 サイトの確認方法

ブラウザ（Chrome, Edge, Safari など）で `index.html` を直接開いていただくだけで、外部サーバーや追加インストールなしですぐにご確認いただけます。
